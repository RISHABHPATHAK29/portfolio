# Rishabh Kumar Pathak — Professional Portfolio Website

A modern, high-performance portfolio website built with **React**, **Vite**, and **Tailwind CSS**, designed in an executive dark-mode aesthetic with glassmorphism and cyan/purple glowing accents.

---

## 🚀 Key Features

- **Hero & Identity**: Highlights your role as **Data & AI Engineer** at **Noventiq Global AI Solution**, your internal job promotion (IJP) from Cloud Engineer, your BIT Mesra MCA background, and your Microsoft AI Odyssey credential.
- **Career Timeline**: Detailed timeline of your progression:
  - *Data & AI Engineer* @ Noventiq (Present)
  - *Cloud Engineer* @ Noventiq (Initial 6 months)
  - *MathWorks Virtual Internship* (MATLAB, Simulink, ML/DL)
  - *Microsoft Future Ready Talent Program* (Azure, AI & Cybersecurity)
- **Interactive Projects Showcase**: Filter by *All*, *AI & ML*, *Cloud & AI*, *Security*, and *Software*:
  - **MANTHAN**: Stock Market Prediction Platform using LSTM & TensorFlow
  - **Krishi Mitra**: Agricultural Assistant Platform (with live Azure deployment button)
  - **EDUHUB**: Smart Educational Platform using Azure Bot Service & NLP
  - **Cybersecurity Vulnerability Testing Tool**: Python defensive testing utility
  - **2D Platformer Game Engine**: Custom Pygame collision and physics system
- **Skills Matrix**: Categorized proficiency grid for AI/ML, Cloud Platforms, Programming, and Data Engineering.
- **Certifications & Honors**: Microsoft AI Odyssey (Applied Skills in NLP, CV, Doc Intelligence), VIP Pass to Microsoft AI Tour Bangalore, and MathWorks Onramp certifications.
- **Academic Qualifications**: MCA & BCA from Birla Institute of Technology (BIT) Mesra.
- **Interactive Resume Modal**: Recruiters can view your full CV and print/save it directly as a PDF.
- **Direct Contact & Form**: Instant email copy button, phone link, social profiles, and inquiry form.

## 🛠️ Getting Started

### 1. Run Development Server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### 2. Build for Production
```bash
npm run build
```
Output will be generated in the `dist/` directory.

### 3. Deploy to Azure Static Web Apps / Vercel / GitHub Pages
- **Azure Static Web Apps**:
  - Build Command: `npm run build`
  - Output Location: `dist`
- **Vercel / Netlify**:
  - Automatically detected with Vite preset.
